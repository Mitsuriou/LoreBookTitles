# Lore Book Titles

A client-side [Vintage Story](https://www.vintagestory.at/) mod. Every lore book shows up as "Aged lore book" or
"Rotten lore book", so you can't tell them apart without opening them. This mod shows each book's real title and
its chapter number, e.g. "Title [2/8]":

- in the inventory tooltip
- above the hotbar
- in the info panel when looking at a book on a bookshelf

The title appears once the book has been read for the first time, because that is when the game assigns a story
and a chapter to it.

**Works in any language:** titles come straight from the game's own translations, so they show up in whatever
language your game is set to.

**Client-side:** only install it on your own game, nothing is needed on the server. Tested on a LAN game, joining
another player's world.

## Install

Download the mod zip from the [Vintage Story ModDB](https://mods.vintagestory.at/lorebooktitles) or the
[GitHub releases](https://github.com/Mitsuriou/LoreBookTitles/releases) and put it as is in
`%APPDATA%\VintagestoryData\Mods`. Requires Vintage Story 1.22.

## How it works

When a lore book is first read, the game writes the story's title (`titleCode`), its code (`discoveryCode`) and the
chapter (`chapterIds`) on the book, but the item name ignores them. A Harmony postfix on `ItemBook.GetHeldItemName`
replaces the name with the translated title, followed by the chapter out of the story's chapter count
(read from the game's `config/lore/` assets).

## Building

Requires the .NET 10 SDK and Vintage Story 1.22. The project finds the game through the `VINTAGE_STORY` environment
variable, or `%APPDATA%\Vintagestory` by default.

- `dotnet build`, then the `Client` launch profile (F5 in Visual Studio) starts the game with the mod loaded.
- `dotnet build -c Release` also creates `bin/Release/LoreBookTitles_<version>.zip`, ready to upload.
